# תזכיר לי · Remind Me

אפליקציה אישית למשימות, ימי הולדת ורשימות קניות, עם תזכורות. בעברית, באנגלית וברוסית.

## מה יש באפליקציה

- **היום שלי** — מה מתוכנן היום: משימות, ימי הולדת, רשימות קניות, ומה נשאר פתוח מימים קודמים. אפשר לעבור ליום אחר.
- **משימות** — עם תאריך, שעה, חזרה (יומית, שבועית בימים נבחרים, חודשית) וחשיבות. מתוך ההתראה: ״בוצע״ או ״הזכר בעוד שעה״.
- **ימי הולדת** — תזכורת ביום עצמו ו/או יום לפני. מוצג הגיל, ויש כפתור חיוג. ל־29 בפברואר יש כלל לשנים לא מעוברות.
- **רשימות קניות** — רשימה שמשויכת ליום, עם תזכורת. הוספה מהירה עם Enter, השלמה אוטומטית, כמויות, שיתוף בוואטסאפ, שכפול, והעברת מה שלא נקנה ליום אחר.
- **יומן** — לוח חודשי מלא עם נקודות בצבעים: כחול למשימות, ורוד לימי הולדת, ירוק לקניות. מוצגים גם תאריך עברי וחגים. לחיצה על יום פותחת את מה שיש בו.
- **עיצוב** — מצב כהה אוטומטי, גופן Rubik ורטט קל בלחיצות.
- **הגדרות** — שפה, שעת תזכורת ברירת מחדל, הסתרת תוכן במסך הנעילה, הצגה או הסתרה של כל מודול, גיבוי ושחזור, ומחיקת כל הנתונים.

כל הנתונים נשמרים בטלפון בלבד. אין שרת ואין חשבון.

---

## שלב 1 — הכנת המחשב (פעם אחת)

1. מתקינים את **Node.js** בגרסת LTS מהאתר nodejs.org.
2. פותחים את התיקייה `remindme` (אחרי חילוץ מה־zip).
3. פותחים בה טרמינל:
   - **Windows:** קליק ימני בתוך התיקייה, ואז ״Open in Terminal״.
   - **Mac:** קליק ימני על התיקייה, ואז ״New Terminal at Folder״.
4. מריצים:

```
npm install
npm run setup
```

הפקודה השנייה מתקינה את כל הספריות בגרסאות שמתאימות זו לזו.

## שלב 2 — לנסות בטלפון עכשיו (חינם, אייפון ואנדרואיד)

1. מתקינים בטלפון את האפליקציה **Expo Go** (מ־App Store או מ־Google Play).
2. מריצים במחשב:

```
npx expo start
```

3. סורקים את קוד ה־QR שמופיע:
   - **אייפון:** עם המצלמה הרגילה.
   - **אנדרואיד:** מתוך Expo Go.
4. אם הטלפון והמחשב לא מחוברים לאותה רשת Wi‑Fi, מריצים במקום זה `npx expo start --tunnel`.

> ב־Expo Go יכולה להופיע אזהרה על ״Push notifications״. אפשר להתעלם ממנה: האפליקציה משתמשת בהתראות מקומיות, והן עובדות.
>
> בשלב הזה האפליקציה נפתחת דרך Expo Go, וצריך שהמחשב יריץ את `npx expo start`. לשימוש יומיומי עוברים לשלב 3.

## שלב 3 — התקנה קבועה

### אנדרואיד — הדרך הקלה ביותר
בכל עדכון של הקוד ב־GitHub נבנה אוטומטית קובץ התקנה חדש.
אותו מורידים מדף ה־Releases של הריפו: נכנסים לגרסה האחרונה, לוחצים על `RemindMe.apk` ומתקינים.
את אותו קישור אפשר לשלוח לחברים.

### אנדרואיד דרך EAS (אופציה נוספת)

1. נרשמים בחינם ב־expo.dev.
2. במחשב:

```
npm install -g eas-cli
eas login
eas build -p android --profile preview
```

3. בסוף מקבלים קישור לקובץ APK. פותחים אותו בטלפון ומתקינים (צריך לאשר ״התקנה ממקורות לא ידועים״).
4. **לחברים:** פשוט שולחים להם את אותו קישור.

### אייפון

התקנה קבועה באייפון דורשת חשבון **Apple Developer** (‏99$ לשנה). אחרי שיש חשבון:

```
eas build -p ios --profile production --auto-submit
```

האפליקציה עולה ל־**TestFlight**, ומשם אפשר להזמין את עצמך ואת החברים במייל.
בלי חשבון אפשר להמשיך להשתמש ב־Expo Go (שלב 2).

## עדכון אחרי שינוי בקוד

- **אנדרואיד:** מריצים שוב את `eas build -p android --profile preview` ומתקינים את ה־APK החדש. הנתונים נשמרים.
- **אייפון:** מריצים שוב את פקודת ה־iOS.

## גיבוי

הגדרות ← ״ייצוא גיבוי״. הגיבוי נשלח כטקסט, למשל לעצמך בוואטסאפ.
לשחזור: הגדרות ← ״שחזור מגיבוי״ ← מדביקים את הטקסט.
כדאי לגבות לפני מעבר לטלפון חדש.

## למפתחים

```
App.js                  ניווט, טאבים, סנכרון התראות
src/store.js            נתונים + שמירה מקומית (AsyncStorage) + הגירות
src/logic/              לוגיקה טהורה: תאריכים, חזרות, ימי הולדת, תכנון התראות
src/notifications.js    שכבת expo-notifications
src/i18n/               תרגומים: עברית, אנגלית, רוסית (כולל צורות רבים ברוסית)
src/screens/            המסכים
src/ui.js               רכיבי ממשק + כיוון RTL/LTR
tests/logic.test.js     52 בדיקות ללוגיקה
```

- **כיוון המסך:** האפליקציה מנהלת את הכיוון (RTL/LTR) בעצמה, ולכן החלפת שפה עובדת מיד, בלי הפעלה מחדש.
- **התראות:** בכל שינוי מחשבים מחדש את 30 הימים הקרובים, עד 60 התראות. זה בגלל ש־iOS מגביל ל־64 התראות ממתינות.
- **שעות:** כל התזכורות לפי השעון המקומי של הטלפון.
- **מזהה האפליקציה:** `com.remindme.personal` (נקבע ב־`app.json`). אפשר לשנות אותו לפני ההעלאה הראשונה לחנות. אחרי ההעלאה הוא קבוע.
